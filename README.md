# InstaPulse 📸

> Modern, responsive social media web application inspired by Instagram, engineered with React 19, Vite, Tailwind CSS v4, Lucide Icons, and Zustand.

## ✨ Features

- **📱 Dynamic Feed:** High-fidelity Instagram feed with likes, bookmarking, threaded comments, stories rail, and user profile links.
- **🔍 Explore & Discovery:** Grid view with categorized content discovery, hashtag indexing, and instant modal view.
- **🎬 Reels Player:** Vertical video feed simulator with interactive action bar (likes, comments, share, audio tracking).
- **💬 Direct Messaging:** Real-time chat UI with active conversations, search, and message history.
- **🔔 Notifications Center:** Activity feed tracking new likes, comments, mentions, and follows with unread status badges.
- **👤 Profile Management:** Comprehensive profile page with post grid, saved bookmarks, tagged media, and bio metrics.
- **➕ Post Creation:** Interactive create modal supporting image uploads, captions, hashtags, and location tagging.
- **⚡ Supercharged Performance:** Lazy-loaded routes (`Suspense` + dynamic imports), responsive sidebar layout, and instant state synchronization with Zustand.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/brysonnn1704/instapulse.git
cd instapulse

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
